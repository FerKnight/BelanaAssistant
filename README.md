# Belana Assistant
Guía no oficial en español de Mongil: Star Dive. Sitio estático (PWA), sin servidor.
## Publicar en GitHub Pages
Sube estos archivos a un repositorio → Settings → Pages → Deploy from a branch → `main` / root.
## Datos e imágenes
- Datos: `data/*.json`. Imágenes: `img/personajes/<nombre>.webp`, `img/artefactos/<nombre>.webp`.
- Fuentes: mongil.wiki.gg (CC BY-SA 4.0), Kaiden.gg. Contenido reescrito, no copiado. Sitio de fans, no oficial; Mongil: Star Dive es de Netmarble.
