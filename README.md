# Belana Assistant

Guía en español de Mongil: Star Dive, instalable como PWA.

## Archivos (súbelos todos juntos a la raíz del repositorio)
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

## Publicar con GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Actualizar
Al cambiar index.html, sube también sw.js con el número de VERSION aumentado
(por ejemplo belana-assistant-v3 → belana-assistant-v4).
